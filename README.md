## Mohammad Ahmad

I'm a PhD student in Computer Science at [The University of Texas at San Antonio](https://www.utsa.edu/), advised by [Dr. Mimi Xie](https://sites.google.com/view/mxie) in the ASIC Lab. My research is on in-memory computing architectures for machine learning, built on domain wall (racetrack) memory and other novel hardware.

**Research interests:** Computer Architecture · In-Memory Computing · Domain Wall Memory · Stochastic Computing · Embedded Systems · TinyML · ML on Novel Hardware · Intermittent Computing · IoT

### Currently working on

- **In-memory computing with domain wall memory**: an architecture that computes directly on stored data, cutting the data movement that dominates energy in ML workloads. Evaluated from circuit to system with LTSpice, NVSim and RTSim.
- **Stochastic computing CNNs on domain wall memory**: a stochastic computing CNN accelerator built on domain wall in-memory computing, with the algorithm (stream generators, accumulators, activations, stream length) and its hardware cost designed together.
